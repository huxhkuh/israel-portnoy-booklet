# להשקיע בנכס בלי לשקוע

דף נחיתה וקורא חוברת בעברית וב־RTL לישראל פורטנוי. האתר סטטי, והספריות הדרושות כלולות מקומית. אין צורך בהתקנת חבילות להרצה.

הכיוון שסוכם: אתר עסקי לישראל ובתוכו עמוד ייעודי לחוברת. הפרויקט הנוכחי מתמקד בעמוד החוברת ובקורא; דף הבית העסקי ייבנה בהמשך. ארבעת הנושאים מקושרים ישירות לפרקים, ואזור המחבר מציג היכרות המבוססת על החוברת.

תצוגה: https://huxhkuh.github.io/israel-portnoy-booklet/

קריאה: https://huxhkuh.github.io/israel-portnoy-booklet/read.html

## הפעלה

בתיקייה זו הריצו `npm start`, ואז פתחו http://127.0.0.1:4173/?v=3 . בדיקת תחביר: `npm run check`.

הקורא נמצא ב־http://127.0.0.1:4173/read.html . קישור לעמוד ומצב תצוגה: `read.html#page=17&mode=pdf` או `read.html#page=17&mode=text`. בלי פרמטר mode נפתחת קריאה נוחה בכל המסכים; אפשר לבחור תצוגת PDF. יש להשתמש בשרת HTTP, ולא לפתוח את קובצי ה־HTML ישירות.

## קבצים

- index.html / styles.css: דף הנחיתה. הכותרת היא טקסט חי בפונט Karantina Bold, שנבחר בגלל האותיות המרובעות, הזוויתיות והצפופות המזכירות את חיים גוטמן. הפונט צר וגבוה יותר מהמקור; גודל הכותרת והריווח מותאמים לדסקטופ ולמובייל. הגוף והמותג משתמשים ב־Assistant וב־Rubik. כל הפונטים מוגשים מקומית ברישיון OFL, המצורף בתיקיית הפונטים. קובץ הפונט של Windows אינו נכלל במאגר.
- app.js: סימון המקטע הפעיל בניווט.
- reader.js: קישורי המשך קריאה בדף הנחיתה, עם תמיכה בחזרה מדף הקריאה ובטאב נוסף.
- read.html / read.css / read.mjs: קורא ייעודי, גלילה רציפה, חיפוש, טקסט רספונסיבי, גודל תצוגה, תוכן עניינים וקישור לעמוד.
- assets/booklet/manifest.json: הטקסט המקורי של 21 העמודים ותוכן העניינים.
- assets/icons.svg: אייקוני מסמך, טלפון ומייל מקוריים שנוצרו לאתר, לצד סמלי Phosphor Regular. הרישיון והגרסה של Phosphor ב־assets/vendor/phosphor.
- assets/vendor/pdfjs: PDF.js 6.5.438, worker, CSS ותלויות מקומיות, עם רישיונות. הקורא טוען את שלושת מודולי legacy הרשמיים מאותה גרסה לתאימות רחבה יותר לדפדפנים, כולל polyfills חסרים.
- server.cjs: שרת מקומי בלבד, כולל MIME למודולים ותמיכה בטווחי בתים ל־PDF.

## החוברת והנתונים

ה־PDF הקל שוקל 2.83MB ומכיל את אותו טקסט, עימוד וקישורים של המקור. המקור (15.31MB) נשמר ללא שינוי בתיקיית assets. תיקיית המקור של החוברת לא שונתה. הכריכה, האיורים והתוכן מבוססים על גרסת ההפצה הציבורית המעודכנת.

מספר העמוד האחרון נשמר ב־localStorage בדפדפן זה בלבד. אין מעקב. הקריאה עובדת גם כשהאחסון המקומי חסום. העתקת הקישור מציעה כתובת להעתקה ידנית כאשר הלוח אינו זמין.

## הרשמה לעדכונים

`leads-config.js` ו־`leads.js` מפעילים הרשמה לעדכונים במייל, בטופס בתחתית העמוד ובהצעת יציאה עדינה. [הוראות ההתקנה וקוד השרת](integrations/google-apps-script/README.he.md) כוללים ולידציה, שמירה באותו גיליון פרטי, הסכמה מתועדת ומניעת כפילויות. זהו איסוף לרשימת תפוצה בלבד, ללא שליחת מיילים אוטומטית. ההצעה האוטומטית מופיעה בדסקטופ אחרי קריאה משמעותית ורמז יציאה, פעם אחת בביקור; במובייל יש טופס וכפתור פתיחה ללא חסימת יציאה. נשמרים ב־sessionStorage רק דגלי הצגה/הרשמה ללא פרטים אישיים. הקריאה וההורדות אינן מותנות בהרשמה. אזור הקריאה מציע שלוש אפשרויות: קורא באתר, PDF מלא ו־PDF קל, ללא גלריית עמודים קטנים.

אין חיצים בממשק. כפתורי הניווט בקורא משתמשים בטקסט, והורדה/טלפון/מייל משתמשים במשפחה המקורית 04 שנבחרה: אייקונים מלאים וקומפקטיים. אזור ״אפשר להעביר את הניהול״ משתמש בחלופה 02 שנבחרה: ציטוט טיפוגרפי ממורכז על רקע חם, ומתחתיו קישורים לארבעת הפרקים. סמלי Phosphor הנוספים ורישיונם נשמרו.

כאשר קובץ PDF נחסם בחיבור (למשל אזהרת נטפרי שמוחזרת ב־HTTP 418), הקורא מציג הסבר, מעבר לקריאה נוחה וקישור לפתיחה רגילה בלשונית חדשה. הקישור אינו כולל download, כך שעמוד האזהרה יכול להופיע במקום ניסיון להוריד HTML כקובץ PDF. אין עקיפה או שינוי של הגדרות הסינון. דפדפן שחסרה בו Promise.withResolvers מקבל הודעת תאימות עם אותן חלופות, במקום שגיאת מודול או טעינה שלא מסתיימת.

## פרסום

המאגר מוגש ב־GitHub Pages מענף main ומשורש המאגר. קובץ .nojekyll שומר על הגשה סטטית ללא עיבוד Jekyll. הנתיבים יחסיים כדי לתמוך בכתובת הפרויקט ובקישורים ישירים לקורא. כל עדכון שנדחף לענף main מפעיל פרסום מחדש.

רישיונות הספריות והפונטים החופשיים כלולים בתיקיות assets/vendor ו־assets/fonts. החוברת מבוססת על גרסת ההפצה הציבורית המעודכנת עם הטלפון.

מקור הפונט לכותרת: [Karantina ב־Google Fonts](https://github.com/google/fonts/tree/main/ofl/karantina), בעיצוב Rony Koch. [רישיון OFL 1.1](assets/fonts/Karantina-OFL.txt) מתיר הטמעה באתר והפצה עם שמירת הודעת הזכויות והרישיון. קובץ WOFF2 נוצר מה־TTF הרשמי ללא שינוי הגליפים.

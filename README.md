# להשקיע בנכס בלי לשקוע

דף נחיתה וקורא חוברת בעברית וב־RTL לישראל פורטנוי. האתר סטטי, והספריות הדרושות כלולות מקומית. אין צורך בהתקנת חבילות להרצה.

תצוגה: https://huxhkuh.github.io/israel-portnoy-booklet/

קריאה: https://huxhkuh.github.io/israel-portnoy-booklet/read.html

## הפעלה

בתיקייה זו הריצו `npm start`, ואז פתחו http://127.0.0.1:4173/?v=3 . בדיקת תחביר: `npm run check`.

הקורא נמצא ב־http://127.0.0.1:4173/read.html . קישור לעמוד ומצב תצוגה: `read.html#page=17&mode=pdf` או `read.html#page=17&mode=text`. בלי פרמטר mode נפתחת תצוגת PDF בדסקטופ וקריאה נוחה במובייל. יש להשתמש בשרת HTTP, ולא לפתוח את קובצי ה־HTML ישירות.

## קבצים

- index.html / styles.css: דף הנחיתה. כותרת חיים גוטמן מוצגת כגרפיקה שקופה וחדה, עם טקסט נגיש במבנה הדף. קובץ הפונט של Windows אינו נכלל במאגר. הגוף והמותג משתמשים ב־Assistant וב־Rubik ברישיון OFL, המצורף בתיקיית הפונטים.
- app.js: סימון המקטע הפעיל בניווט.
- reader.js: קישורי המשך קריאה בדף הנחיתה, עם תמיכה בחזרה מדף הקריאה ובטאב נוסף.
- read.html / read.css / read.mjs: קורא ייעודי, גלילה רציפה, חיפוש, טקסט רספונסיבי, גודל תצוגה, תוכן עניינים וקישור לעמוד.
- assets/booklet/manifest.json: הטקסט המקורי של 21 העמודים ותוכן העניינים.
- assets/icons.svg: סמלי Phosphor Regular. הרישיון והגרסה ב־assets/vendor/phosphor.
- assets/vendor/pdfjs: PDF.js 6.5.438, worker, CSS ותלויות מקומיות, עם רישיונות.
- server.cjs: שרת מקומי בלבד, כולל MIME למודולים ותמיכה בטווחי בתים ל־PDF.

## החוברת והנתונים

ה־PDF הקל שוקל 2.83MB ומכיל את אותו טקסט, עימוד וקישורים של המקור. המקור (15.31MB) נשמר ללא שינוי בתיקיית assets. תיקיית המקור של החוברת לא שונתה. הכריכה, האיורים והתוכן מבוססים על גרסת ההפצה הציבורית המעודכנת.

מספר העמוד האחרון נשמר ב־localStorage בדפדפן זה בלבד. אין טופס, מעקב או שידור מידע לשירות חיצוני. הקריאה עובדת גם כשהאחסון המקומי חסום. העתקת הקישור מציעה כתובת להעתקה ידנית כאשר הלוח אינו זמין.

## פרסום

המאגר מוגש ב־GitHub Pages מענף main ומשורש המאגר. קובץ .nojekyll שומר על הגשה סטטית ללא עיבוד Jekyll. הנתיבים יחסיים כדי לתמוך בכתובת הפרויקט ובקישורים ישירים לקורא. כל עדכון שנדחף לענף main מפעיל פרסום מחדש.

רישיונות הספריות והפונטים החופשיים כלולים בתיקיות assets/vendor ו־assets/fonts. החוברת מבוססת על גרסת ההפצה הציבורית המעודכנת עם הטלפון.
